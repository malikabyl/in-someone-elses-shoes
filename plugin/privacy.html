Privacy Policy — Draft

PREPARATION DRAFT — not a final policy or submission approval. Unconfirmed owner decisions are marked below.

This game-specific notice describes verified implementation facts for In Someone Else’s Shoes. It does not replace the separate policies of ChatGPT/OpenAI, GitHub, Cloudflare, GoatCounter or Google.

Provider and scope

The provider is ND SaaS Solutions LLP (ТОО «ND SaaS Solutions»), Kazakhstan. The game includes a ChatGPT MCP service and USA/Japan browser editions. The corporate ndbase.kz policy concerns a different service and is not used as this game's privacy policy.

Chat game data

The MCP service receives tool arguments such as country, selected profession, game actions, amounts, random session identifiers and request identifiers. It stores simulated game state and up to 100 successful request results per session in Cloudflare Durable Objects to operate the game and handle retries. The inspected MCP code does not require an account or payment details. This does not establish what infrastructure logs collect.

The server schedules session deletion 30 days after creation or the latest successful state change. Reading status does not renew this timer. Ending a game marks it finished and does not immediately delete it. This application timer does not establish retention of platform logs or backups.

Browser editions

Browser games save progress in localStorage; the Japan edition also stores a language preference. You can clear these local values using your browser's site-data controls; this does not delete server sessions or infrastructure logs.

Both source editions configure GoatCounter at malikabyl-shoes.goatcounter.com and load its counting script on github.io. The code includes visit and gameplay-event counting. Both editions request Google Fonts. Visiting a page can therefore cause requests to these services. We have not verified account-level retention, access permissions or all data received by those services, and make no claim that analytics is disabled or that no personal data is processed.

Session safety

The MCP code accepts a session identifier without user login. Anyone who obtains a valid identifier may be able to read or change that game. Do not post identifiers in issues, recordings or public chats.
