Data Deletion

Last updated: 22 October 2026

In Someone Else's Shoes does not ask for your name, email or payment details. The only stored game data is the simulated game itself. Here is how to remove it.

Chat games (ChatGPT app)

  1. Delete it now. In the same chat, ask ChatGPT: “Delete my In Someone Else's Shoes game.” It calls the delete_game tool with your session ID, and the game state and stored action results are erased immediately. Afterwards the session can no longer be opened; this cannot be undone.
  2. Automatic deletion. Every chat game is deleted automatically 30 days after it was started or last changed (an action, a new quarter or ending the game). Only viewing the status does not extend this period. Ending a game does not delete it by itself.

Games are identified only by a random session ID that is not linked to your name or account, so we cannot find “your” game from a description. If you no longer have the session ID, the game will be removed automatically within 30 days of its last change.

Browser games

Progress is stored only in your browser. Choose “Start over” in the game, or clear the site data for malikabyl.github.io in your browser settings. This removes the save and, in the Japan edition, the language choice.

Visit statistics and provider logs

Visit statistics (GoatCounter) contain no IP addresses, names or account identifiers, so they cannot be traced back to a person. Network logs kept by GitHub (website hosting), Cloudflare (MCP service), Google (fonts) and OpenAI (ChatGPT) are governed by those providers' own policies; for your ChatGPT conversations, use OpenAI's data controls.
