# Данные японской версии, 1980–2005

Собрано 2026-10-09 из облачной сессии. Скачать файлы напрямую оттуда было
нельзя: страницы FRED, Банка Японии и японских ведомств читались через
читалку, а числа переписывались из прочитанного текста. Поэтому каждое
значение здесь — переписанное, а не скачанное. Перед окончательным
использованием ряды стоит скачать файлами и сравнить (адреса ниже).

Пометки: **П** — первоисточник, **В** — вторичный источник.
